Standardmäßig läuft der Schalter im lokalen Simulationsmodus. Um ihn auf mehreren Geräten live zu testen:

🚀 Wie schalte ich das 100% gratis auf allen Geräten frei?

  1. Gratis API erstellen: Gehe zu JSONbin.io (oder Nutze Supabase/Firebase REST API). Registriere dich kostenlos.
  2. Bin anlegen: Erstelle dort ein Dokument mit dem Inhalt: { "status": "AUS" }.
  3. URL hier eintragen: Kopiere den Link des Bins und deinen Master Key in die Cloud-Konfiguration oben.
  4. Hosten: Lade diese `index.html` Datei kostenlos bei GitHub Pages, Netlify oder Vercel hoch.

Vorteil: Kein PHP, keine Sicherheitslücken, 100% kostenlose Infrastruktur, die niemals abläuft!
